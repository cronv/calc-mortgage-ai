# Ипотечный калькулятор

Публичный калькулятор (banki.ru-style) + встраиваемый виджет для сайтов партнёров.
Единый источник данных (MySQL) и единый API подбора предложений для обоих калькуляторов.

**Стек:** PHP 8.4 / Symfony 7.2 · Angular 20.2 (zoneless, signals, esbuild) · MySQL 8.4 · Nginx · Docker.

## Возможности калькулятора

- **Страница по макету**: тёмная шапка с навигацией, крошки, CTA-ряд, тёмный таб-бар «Ипотека / Рефинансирование», блок предложений банков, рассылка и футер.
- **Режимы расчёта**: по стоимости и по платежу; срок задаётся в годах.
- **Ипотечные программы**: Стандартная, Семейная, Военная, ИТ, Дальневосточная, Арктическая, Сельская (льготные ограничивают ставку сверху); чипы типов жилья со ставками (Вторичка / Новостройка / ДОМ ИЖС).
- **Панель результатов**: платёж, сумма кредита, переплата, общая выплата, рекомендуемый доход, налоговый вычет.
- **График платежей (модалка)**: по годам и по месяцам, **скачивание в Excel (.xlsx)**, **ссылка на расчёт** (параметры в URL, восстановление при открытии), **отправка в Telegram**.
- **Предложения банков**: единый API `/api/v1/calculator/match`, сортировка по платежу, фильтр по программе, заявка в банк из карточки, «Показать ещё».
- **Анкета заёмщика (5 шагов)**: из карточки банка «Отправить заявку» → мастер по макетам: параметры кредита → авторизация по телефону (СМС-код) → контакты (город с автокомплитом) → паспорт и адреса (подсказки адресов, тумблеры) → работа и стаж (зарплатный банк с поиском) → семья (созаёмщики при брачном договоре, маткапитал при детях). Финал — благодарность, **скачивание анкеты в PDF и Word** (lazy pdfmake/docx), **ссылка на заполнение для заёмщика** (`?apply=1&…`), «Назад» на каждом шаге. Кнопка «Подробнее» — прежняя быстрая заявка в модалке.
- **Виджет «Подбор ипотеки»**: форма + табы программ + карточки банков, Shadow DOM, container queries, фолбэк-расчёт при недоступном API, postMessage `mortgageWidget:onSuccess`.
- **Адаптив от 375px** (8 брейкпоинтов) и **кроссбраузерность**: browserslist + автопрефиксы, фолбэк буфера обмена, `@supports` для container queries.

## Запуск одной командой

Нужны только **Docker** и **Docker Compose**. Ничего на хост ставить не надо —
зависимости и сборка выполняются внутри контейнеров.

```bash
make up
```

Что делает `make up`:
1. собирает образы (`docker compose build`);
2. поднимает MySQL, PHP-FPM, Nginx;
3. при первом старте PHP-контейнер сам ставит `composer install`, ждёт БД,
   прогоняет миграции, грузит фикстуры (если БД пуста) и прогревает кэш;
4. в контейнере Node собирает Angular: публичный SPA и виджет (`npm ci && ng build`).

После завершения:

| Что | Адрес |
|-----|-------|
| Публичный калькулятор | http://localhost:8080 |
| Демо встраиваемого виджета | http://localhost:8080/widget/widget-demo.html |
| Healthcheck API | http://localhost:8080/api/health |

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/api/calculate` | платёж, переплата, график |
| POST | `/api/calculate/early-repayment` | график с досрочным погашением и маткапиталом |
| GET | `/api/v1/calculator/match` | единый подбор предложений (SPA + виджет) |
| POST | `/api/v1/application` | приём заявки |
| GET | `/api/health` | статус сервиса и БД |

## Встраивание виджета

Одна строка на сайте партнёра:

```html
<script src="https://widget.ВАШ_ХОСТ.ВАША_ЗОНА/widget/mortgage-widget.js"
        data-partner="demo"
        data-color-primary="#FEBD69"></script>
```

Виджет рендерится в Shadow DOM (изоляция стилей) и шлёт родителю событие
`mortgageWidget:onSuccess` через `postMessage` при отправке заявки.

| Атрибут | Назначение | По умолчанию |
|---------|-----------|--------------|
| `data-partner` | идентификатор партнёра в заявках | `demo` |
| `data-color-primary` | цвет акцентной кнопки | `#FEBD69` |
| `data-api-base` | базовый URL API | тот же хост |

## Полезные команды

```bash
make ps            # статус контейнеров
make logs          # логи
make front-build   # пересобрать только фронтенд
make db-reset      # пересоздать БД и фикстуры
make test          # тесты backend + frontend
make down          # остановить
make clean         # удалить контейнеры, тома и сборки
```

## Структура

```
backend/    Symfony 7.2 — API, расчёты, парсер программ, миграции, фикстуры
frontend/   Angular 20 — projects/main-app (SPA) и projects/mortgage-widget (виджет)
docker/     Dockerfile PHP, конфиги Nginx
docker-compose.yml, Makefile
```

## Замечания по продакшену

- CORS в `docker/nginx/default.conf` сейчас отражает любой Origin — для прода замените на белый список доменов.
- Фикстуры грузятся только в `dev`/`test` и только если таблица `bank_products` пуста.
- Парсер программ: `make bash` → `php bin/console parser:programs` (при недоступности источника подхватывает демо-набор).
